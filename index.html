    How to Load Publishes

    Quick guides for AutoCAD, pyRevit, and Dynamo

    1. AutoCAD AutoLISP (.lsp)

    • Temporary Load: Type APPLOAD in AutoCAD, select your downloaded .lsp file, and click Load.
    • Permanent Autoload: In the APPLOAD dialog, click Contents under the Startup Suite (briefcase icon), and add the file. Now it loads every time AutoCAD starts.
    • Auto-run: Simply type the custom command (e.g. AREACLS or XYZOUT) in the command line!

    2. Revit pyRevit Extension (.extension)

    • Why loose .py files cannot run alone: In pyRevit, buttons require the directory hierarchy (.extension / .tab / .panel / .pushbutton) with bundle.yaml, icon.png, and ui.xaml (WPF dialogs). A raw .py file dropped alone will not load on the ribbon.
    • 1-Click Install: Download the complete Ludarp_pyRevit_Extension_Full.zip package from the button above.
    • Extract the Ludarp.extension folder into: %APPDATA%\pyRevit\Extensions\
    • In Revit, click pyRevit -> Reload. The entire LUDARP tab with all 7 tools will immediately appear!

    3. Dynamo Visual Script (.dyn)

    • Save the downloaded .dyn file to your standard Dynamo scripts folder.
    • In Revit, go to Manage -> Dynamo Player.
    • Point Dynamo Player to your folder and click Play on the script.
