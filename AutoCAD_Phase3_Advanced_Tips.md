## Week 10 (Days 46-50): Customization & Automation

### Day 46 🎠 — Custom Keyboard Shortcuts & Aliases
**Caption:** Stop using default shortcuts if they don't fit your workflow — build your own.
- CUI – Customize User Interface
- PGP file editing – add/edit command aliases (e.g., make "WD" = Wipeout)
- Reload aliases with REINIT after editing the PGP file
**Hashtags:** #autocadcustomization #cadhacks #powerusertips

---

### Day 47 🎠 — Tool Palettes & Workspaces
**Caption:** Build a workspace that matches how YOU actually work:
- TOOLPALETTES (Ctrl+3) – Create custom tool palettes with your most-used blocks/hatches
- WORKSPACE – Save custom ribbon/toolbar layouts
- CUIEXPORT / CUIIMPORT – Share your custom setup across computers
**Hashtags:** #autocad #workspaces #cadefficiency #powerusertips

---

### Day 48 🎥 — "Building a custom tool palette in 60 seconds"
**Script:** Drag frequently-used blocks and hatches into a new tool palette, rename it, and show one-click insertion afterward.
**Caption:** Set this up once, save hours every week after.
**Hashtags:** #autocad #toolpalettes #cadhacks #productivitytips

---

### Day 49 🖼️ — Hidden Feature: Action Recorder
**Caption:** Repeating the same 10-step process on every drawing? **ACTRECORD** (Action Recorder) lets you record a macro once and replay it with **ACTPLAY** — no scripting knowledge required.
**Hashtags:** #autocad #actionrecorder #cadautomation #powerusertips

---

### Day 50 🎠 — Intro to AutoLISP (No-Code-Experience Version)
**Caption:** You don't need to be a programmer to use basic LISP routines:
- APPLOAD – Load a .lsp routine into AutoCAD
- Free/community LISP routines exist for things like auto-numbering, batch attribute editing, and area labeling
- VLIDE – Visual LISP Editor, for viewing/tweaking existing routines
**Hashtags:** #autocad #autolisp #cadautomation #advancedcad

## Week 11 (Days 51-55): Advanced Drafting Efficiency

### Day 51 🎠 — Advanced Object Snap & Tracking
**Caption:** Precision drafting relies on these:
- OSNAP (OS) – Configure running object snaps
- Polar Tracking (F10) – Snap to precise angles automatically
- Object Snap Tracking (F11) – Track alignment from multiple reference points
- OTRACK – Toggle object snap tracking
**Hashtags:** #autocad #precisiondrafting #cadtips #advancedcad

---

### Day 52 🎠 — Groups & Advanced Selection
**Caption:** Group repeated object sets so you never lose track of them:
- GROUP (G) – Create a named group of objects
- UNGROUP – Break a group apart
- PICKSTYLE – Toggle group selection behavior
- Selection Cycling (Ctrl while clicking overlapping objects)
**Hashtags:** #autocad #cadgroups #drafting #advancedcad

---

### Day 53 🖼️ — Hidden Feature: Superhatch (Express Tools)
**Caption:** Need to hatch with an image, block, or external drawing instead of a standard pattern? Express Tools' **Superhatch** lets you do exactly that — great for material call-outs and site plans.
**Hashtags:** #autocad #expresstools #hatching #advancedcad

---

### Day 54 🎥 — "5 Express Tools you're not using"
**Script:** Quick demo of:
1. TCOUNT – Auto-number text objects sequentially
2. TXTEXP – Convert text to polylines/outlines
3. EXTRIM – Trim multiple objects to a cutting boundary at once
4. MPEDIT – Edit multiple polylines simultaneously
5. LSPINCLUDE – Load Express Tools automatically at startup
**Caption:** Turn on Express Tools if you haven't already — free with every install.
**Hashtags:** #autocad #expresstools #cadhacks #advancedcad

---

### Day 55 🎠 — Advanced Array & Pattern Techniques
**Caption:** Beyond the basics:
- Associative Arrays – edit one item, updates the whole array automatically
- Array along a 3D path (for structural/civil layouts)
- Editing array item count/spacing live via grip points
- Converting an array to independent objects (ARRAYEDIT > Explode)
**Hashtags:** #autocad #advancedarrays #cadtips #civilengineering
