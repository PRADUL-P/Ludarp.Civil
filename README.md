# CivilCut — Creator Studio & Shortcut Hub

CivilCut is a premium web application and content automation tool designed for civil engineering, architectural, and design influencers. It enables creators to instantly generate stylized, ready-to-post Instagram graphics (carousels, reels, single posts), draft optimized captions, check off content milestones in an interactive campaign calendar, and parse AI-generated text drafts.

## 🚀 Key Features

* **Creator Studio**: Live aspect-ratio scaling (1:1 square posts & 9:16 reels/stories) with multiple professional blueprint and tech color presets.
* **AutoCAD Content Calendar**: A fully interactive 82-day AutoCAD curriculum tracker grouped by Phase and Week, permitting creators to mark days as completed, track overall progress, and load content drafts directly into the builder.
* **Smart AI Draft Importer**: Paste raw copy-paste text outputs from ChatGPT or Claude, and let the system intelligently parse and map the software, shortcuts, descriptions, tutorials steps, and pro-tips directly into the editor card.
* **Public Shortcut Hub**: A searchable, filterable directory of common shortcuts for AutoCAD, Revit, Civil 3D, ETABS, and SketchUp that followers can use as a link-in-bio resource.
* **Bulk Zip Exporter**: Render the entire shortcut database into styled PNG graphics and an Instagram captions catalog text file, packaged in a single ZIP download.

## 🛠️ Technology Stack

* **Structure**: HTML5 (semantic layout)
* **Styling**: Custom CSS3 variables & flexbox/grid layout
* **Logic**: Vanilla ES6 JavaScript
* **Libraries**: `html2canvas` (visual layout rasterizer), `jszip` (bulk archive compressor)

## 📦 Setup & Usage

Simply open `index.html` in any web browser to run the application locally. No build steps or server configurations required!
